# C++ & x86 Inline Assembly: Conditionals ⚙️

Цей проєкт демонструє використання низькорівневих асемблерних вставок (Inline Assembly) у C++ для реалізації умовних виразів та логічних розгалужень. Розроблено в рамках лабораторної роботи з вивчення архітектури мікропроцесорів та оптимізації коду.

## 🧠 Реалізована логіка
Програма обробляє три вхідні змінні (`A`, `B`, `C`) і за допомогою регістрів процесора x86 перевіряє наступну складену умову:
```cpp
if ((A >= 7 && B <= 3) || C == 10) {
    EAX = 30;
} else {
    EAX = -30;
}
